# SmartStudy – Study Planning and Progress Tracking App

SmartStudy is an Android application designed to help students organize their study activities, manage tasks, and track their learning progress.

## Features

- Study task and course management
- Study timer for organizing study sessions
- Tracking completed tasks and study progress
- Weekly progress overview
- User authentication
- Data storage and synchronization using Firebase

## Technologies

- **Programming Language:** Kotlin
- **User Interface:** Android Jetpack Compose
- **Authentication:** Firebase Authentication
- **Database:** Firebase Realtime Database
- **Build System:** Gradle
